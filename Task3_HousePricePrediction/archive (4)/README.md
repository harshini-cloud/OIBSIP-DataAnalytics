# House Price Prediction

## 📌 Objective
Predict house prices using Machine Learning (Linear Regression).

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📂 Dataset
House Price Prediction Dataset

## 📊 Project Workflow
- Data Loading
- Data Cleaning
- Feature Selection
- Train-Test Split
- Linear Regression Model
- Model Evaluation
- Visualization

## 📈 Results
The model predicts house prices based on important property features such as square feet, number of bedrooms, resale status, and construction status.
