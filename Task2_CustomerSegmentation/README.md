# Customer Segmentation Analysis

## 📌 Objective
This project segments mall customers into different groups based on their Annual Income and Spending Score using the K-Means Clustering algorithm.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📂 Dataset
Mall Customers Dataset

## 📊 Project Workflow
- Data Loading
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Elbow Method
- K-Means Clustering
- Customer Segmentation
- Business Insights

## 📈 Results
The customers were successfully divided into 5 clusters based on their purchasing behavior. This segmentation can help businesses create targeted marketing strategies.
